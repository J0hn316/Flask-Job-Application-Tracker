# Flask Job Application Tracker

A full-stack job application tracking web app built with **Python**, **Flask**, **SQLite**, **Jinja templates**, **HTML**, and **CSS**.

This project helps users organize their job search by tracking applications, updating statuses, searching/filtering records, and viewing dashboard statistics that summarize job hunt progress.

---

## Features

- Add new job applications
- View all tracked applications
- Edit existing applications
- Delete applications
- Server-side form validation
- Flash messages for successful actions and errors
- Search by company name or job title
- Filter by application status
- Combine search and status filters
- Dashboard statistics:
  - Total applications
  - Applied
  - Interviewing
  - Rejected
  - Offers
- SQLite database persistence
- Environment-aware secret key configuration
- GitHub-ready structure with `.gitignore`, `.env.example`, and `requirements.txt`

## Core Data Model

Each job application stores:

| Field          | Purpose                                           |
| -------------- | ------------------------------------------------- |
| `id`           | Unique application ID                             |
| `company_name` | Company applied to                                |
| `job_title`    | Role title                                        |
| `status`       | Current application stage                         |
| `date_applied` | Date the application was submitted                |
| `job_url`      | Optional job posting URL                          |
| `location`     | Optional location such as Remote, Hybrid, or city |
| `notes`        | Optional personal notes                           |
| `created_at`   | Timestamp generated by SQLite                     |

## Application Statuses

The tracker supports these statuses:

- **Applied**

- **Offer**

## Flask Routes

| Route                       | Method | Purpose                                                |
| --------------------------- | ------ | ------------------------------------------------------ |
| `/`                         | `GET`  | Display dashboard, filters, form, and job applications |
| `/`                         | `POST` | Add a new job application                              |
| `/applications/<id>/edit`   | `GET`  | Show the edit form for one application                 |
| `/applications/<id>/edit`   | `POST` | Update an existing application                         |
| `/applications/<id>/delete` | `POST` | Delete an application                                  |

## Main App Flow

### Create Application

```text
User submits add form
        ↓
Flask reads form data from request.form
        ↓
validators.py checks the input
        ↓
If valid, database.py inserts into SQLite
        ↓
Flask redirects home
        ↓
Success flash message appears
```

### Search and Filter

```text
User submits GET filter form
        ↓
URL receives query parameters
        ↓
Flask reads request.args
        ↓
database.py builds a filtered SQL query
        ↓
Matching applications render on the homepage
```

### Dashboard Stats

```text
SQLite aggregate query counts all applications by status
        ↓
Flask passes stats dictionary into the template
        ↓
Stat cards render at the top of the homepage
```

## Validation Rules

Before saving or updating an application, the app validates:

- Company name is required
- Job title is required
- Status is required and must be one of the allowed statuses
- Date applied is required
- Date applied must be a valid ISO-style date
- Job posting URL is optional, but if supplied:
  - It must start with `http://` or `https://`
  - It must include a valid domain

Validation logic lives in:

```text
validators.py
```

## Search and Filtering

The tracker supports:

### Search by:

- Company name
- Job title

### Filter by:

- Applied
- Interviewing
- Rejected
- Offer

### Example query-string filter:

```text
/?search=python&status=Interviewing
```

This returns applications where:

- Company or job title contains `python`
- Status equals `Interviewing`

## Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd flask-job-application-tracker
```

---

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

---

### 3. Activate the Virtual Environment

#### Windows PowerShell

```powershell
.venv\Scripts\Activate.ps1
```

#### Git Bash

```bash
source .venv/Scripts/activate
```

#### macOS/Linux

```bash
source .venv/bin/activate
```

---

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 5. Run the Flask App

```bash
flask --app app run --debug
```

---

### 6. Open in the Browser

Visit:

```text
http://127.0.0.1:5000
```

## Environment Variables

The app supports a `SECRET_KEY` environment variable for Flask session and flash message support.

An example file is included:

```text
.env.example
```

Example:

```env
SECRET_KEY=replace-with-a-random-secret-key
```

For local learning, the app falls back to a development key if no environment variable is set.

This project uses several good backend habits:

- Parameterized SQL queries with `?` placeholders
- Server-side input validation
- POST requests for destructive actions like delete
- Environment-based secret key support
- Local database and secret files excluded from Git
- Query-string status filters restricted to approved values
